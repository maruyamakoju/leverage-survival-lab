# How Claude Code Built This Project

このリポジトリは、ヒューマン(@maruyamakoju)と Claude Code の共同作業で構築された。
本ドキュメントは、AI for Science / 自律エージェント運用の事例として、何をAIが、何を人間がやったかを正直に記録する。

## ヒューマンが提供したもの

1. **企画書**(`docs/`)— 4 仮説のプレ・レジストレーション、KPI、8 週間の roadmap
2. **倫理境界**— 実弾投入禁止、データはBinance公開APIのみ、否定的結果も等しく公開
3. **方針判断**— ブランチ・GitHub 公開・Twitter スレッド原稿の最終確認
4. **「バンバン進めて」スタンス** — 細かい意思決定は委譲

## Claude Code が自走したもの

1. **アーキテクチャ設計** — 5 層構造の決定、各層の責務分割
2. **コード実装** — 全 1,082 行の src/ + 全 80 テスト
3. **数式の検証** — 清算価格、手数料計算、Wilson CI、Bonferroni 補正
4. **デバッグ** — 100倍レバの清算価格期待値の誤記を発見・修正、pandas 3.0 のセグフォルト回避策
5. **データ取得** — ccxt スクリプト + 6 年分 OHLCV/funding 取得
6. **実験設計と実行** — モンテカルロ・グリッド、N=270k シミュレーション
7. **統計検定** — 4 仮説の正式検定 + マークダウンレポート
8. **可視化** — ヒートマップ、equity curves、H3 crossover figure
9. **ドキュメンテーション** — README(JP/EN)、ブログ草稿、Twitter スレッド原稿

## 反復ループの形

```
人間: "やってほしいテーマ + 厳格性の縛り" を伝える
  ↓
Claude: タスク分解、コード実装、テスト書く、実行
  ↓
Claude: 結果を読み取り、次の仮説を立てる、再実行
  ↓
Claude: 失敗を発見 → デバッグ → 修正 → 再実行
  ↓
人間: 大枠の方針を決め(コミット、push、公開先)、Claude が詳細を実行
```

## 自律実行の証拠

`results/agent_log.jsonl` に 14 サイクル分の自律実行履歴(BTC/ETH/SOL × H1〜H4)。
各エントリは:
- 仮説名・operationalization
- データセット・seed
- grid spec パラメータ
- 開始/終了 timestamp
- insight 文字列

を含む append-only JSONL。

## Claude Code の限界(正直に)

1. **長時間プロセスでのメモリ問題** — Windows ネイティブクラッシュは Claude Code 自体の問題ではないが、回避策(subprocess 分割)は人間の介入が必要だった部分もある
2. **マイクロな数値判断** — 100x 清算価格の docstring に誤記をした。テストで気づいたが、最初のフィードバック・ループは人間より遅い
3. **発信の文脈判断** — 「このツイートが炎上するか」みたいな日本のSNS文化判断は人間に委ねた

## 学んだこと

- **プレ・レジストレーション** をプロジェクト初日にコミットするのは、Claude Code が後で「都合の良い解釈」をしないための自己拘束として有効
- **タスクを細かく decompose して並列に投げる** のが Claude Code の強み(検定・図・ドキュメントを同時並行)
- **テスト → 実装 → 実験 → 分析 → ドキュメント** のサイクルを 1 ターンで回せるので、人間1人の意思決定速度がボトルネック化する
